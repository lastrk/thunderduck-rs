# v2 Slice A — τ substrate landing (types + plan + protobuf converter + SparkSQL front-end + dispatch)

**Date:** 2026-07-02. **Baseline:** commit `e604193`. **Result:** all three sub-slices (A.1 + A.2 + A.3) landed on branch `feat/v2-transpiler`, corpus `core_v2` 153/324 → 0/324 (designed regression per ADR-022).

## Summary

Slice A is the foundational substrate for the v2 restart. Before A.1: `crates/core/src/transpiler_v2/` had been deleted at `d846663` (morph-track discard); the `THUNDERDUCK_TRANSPILER=v2` env var was a no-op that routed every request through legacy. After A.3: τ owns the protobuf converter, the SparkSQL front-end, its own `Expression` enum, its own `TypeInferenceEngine`, and the sole dispatch site. τ's `generate()` returns `Err(EmissionError::UnsupportedOp)` for every input — a Thunderduck-boundary error per ADR-022 that surfaces as `Status::unimplemented` to the caller. Every corpus case now surfaces τ's boundary error; Slices B (analyzer) and C (emission) will climb from 0/324 upward.

## Design decisions ratified

- **28 Expression variants** (Spark 4.1.1 parity, not 21 as the /goal literally stated). Open Question 3 escalated by architect; user accepted.
- **`EmissionError` τ-local location** (`crate::transpiler_v2::error`) with `#[from]` composition into `ThunderduckError`. Open Question 2.
- **`PlanPlaceholder` / `BaseTypesPlaceholder` unit types at A.1** — deleted at A.2 when `CommonAst` / `BaseTypes` land. Open Question 1.
- **`Schema` type alias** at `mod.rs` (`pub type Schema = crate::types::StructType;`). Open Question 4.
- **No new dev-deps** — INV10 walker uses `std::fs::read_dir` recursion. Open Question 5.
- **Subquery variants carry `Box<PlanPlaceholder>` at A.1, `Box<CommonAst>` at A.2.** Open Question 6.
- **`SparkDialect` duplicated** into `parser_v2/dialect.rs` per Open Decision 1 Option 1b. Zero shared substrate at the parser layer.
- **Hybrid V2RelationConverter exhaustiveness** — structured shapes in A.2; complex shapes surface as `UnsupportedProtoShape` until owning slice covers them. Open Decision 2 Option 2c.
- **Approach A hand-written match arms** for emission dispatch — permanent per Open Decision 7.
- **B-layer module `crates/core/src/transpiler_v2/rewrites.rs`** — planned but not created at Slice A (Slice C.1 creates it empty; Slice G populates with SQL desugarings). Open Decision 6.

## Iteration methodology observations

- **Three sequential sub-slice passes.** No sub-slice sub-split (A.1, A.2, A.3 each ran as one `/new-feature` pass under `/goal`). 3 of 5 pass budget consumed.
- **Zero HALT-AND-FLAG triggers.** The 12 → 153 baseline discrepancy discovered at preflight was a scope-file correction, not a HALT-AND-FLAG (no new architectural decision surfaced).
- **Parallel review + perf stages** worked well for A.2 (halved wall-clock time).
- **Docs stage** was NO_CHANGES_NEEDED for all three sub-slices — substrate work doesn't drive doc updates until Slice K's legacy cleanup.
