## Architecture decisions ratified

- **Single-pass fused implementation.** The plan proposed three separate transformations with a pointer-identity side-channel schema map. Coder chose fusion into one bottom-up traversal to eliminate the fragile side-channel; reviewer confirmed section comments preserve the three-stage narrative and semantic correctness is intact.
- **`AnalyzerError` bridge via Display prefix** (Open Question 1 Option a) — `[SPARK-EMULATED]` / `[TDCK-BOUNDARY]` prefix strings preserve ADR-022's `EmissionError`-is-Thunderduck-boundary contract while enabling grep-classification.
- **`CommonOp::SetOp` added inside Slice B** (Open Question 2) — additive; front-ends surface `UnsupportedProtoShape` for SetOp proto shapes until they lower into it.
- **`FileScan` schema inference boundary** (Open Question 3) — declared-schema resolves; schema-less → `PuntedOperator("FileScan", "Slice F")`.
- **Set-op widening covers three set-ops** (Open Decision 5 Option 5b) — UNION + INTERSECT + EXCEPT. UNION BY NAME → `PuntedOperator("SetOp[UNION BY NAME]", "Slice G")`.
- **Outer-join nullability derivation** — LEFT/RIGHT/FULL flip via `flip_all_nullable`; INNER/CROSS preserve; SEMI/ANTI = left only. `derived_left_schema`/`derived_right_schema` retained on `TypedOp::Join` for Slice E's emitter.
- **Central ambiguity check** (fix pass H1) — `resolve_column` counts case-insensitive matches; > 1 → `AmbiguousColumn` regardless of expression context. Redundant join-condition walker deleted.

## Fix pass — 4 items closed

- **H1 (High):** Central ambiguity check in `resolve_column`. Projections/Filter/Sort over Joins now correctly surface `AmbiguousColumn` (previously silently first-hit).
- **H2 (High):** Redundant `check_join_condition_ambiguity` walker deleted — subsumed by H1's central fix.
- **M1 (Medium):** Qualified `Star` with unknown qualifier → `AnalyzerError::UnknownColumn` (previously silently expanded to `*`).
- **M2 (Medium):** Arity mismatches in set-op + Values use `AnalyzerError::Other` (previously misused `TypeMismatch` with `Unresolved` sentinels).
