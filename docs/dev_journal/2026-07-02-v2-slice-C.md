## Architecture decisions ratified

- **Approach A permanent** (ADR-009 + Open Decision 7). `dispatch_op` is a hand-written 14-arm match on `TypedOp`; `render_expr` is a hand-written 28-arm match on `Expression`. Zero data-driven interpreter. Zero proc-macro codegen.
- **Two error categories** (ADR-022). Every emission-side error is Thunderduck-boundary (`UnsupportedOp`, `UnsupportedExpression`, `UnsupportedFunction`, `UnsupportedProtoShape`). No Spark-emulated variants leaked into emission.
- **INV3 grep barrier active** — `emission.rs` imports only `super::{ast, analyzer, base_types, error, expression, type_inference}` and `crate::types::{DataType, StructField, StructType}`. No `use crate::generator::*` / `crate::functions::*`. Self-test-safe by scanning only pre-`#[cfg(test)]` region and building needle strings at runtime.
- **§5.4 `render_tail` CTE anchor** landed as real code. `render_tail` is `#[allow(dead_code)]` under Decision 13-A (no `TypedOp::Tail` yet) but its CTE shape (`WITH __td_child AS (child_sql) SELECT * EXCLUDE (__td_row_num__) FROM (... ROW_NUMBER() OVER () ...) WHERE __td_row_num__ > (SELECT COUNT(*) FROM __td_child) - n`) is asserted by `render_tail_uses_cte_not_double_embed`.
- **§5.1 separation ratified.** `spark_return_cast` and `spark_aggregate_return_cast` land as two distinct `fn` items; test compares raw `fn` pointers to prevent accidental unification.
- **§5.6 `Cow::Borrowed` fast path is honest post-perf.** After Stage 4 H1, `quote_ident` performs zero heap allocation on the safe-identifier path — reserved-word check is byte-level `ascii_ci_cmp` + `binary_search_by` over the sorted `DUCKDB_RESERVED`.

## Fix pass — 3 items closed

- **H1 (High):** Deleted dead `EmittedSql` newtype whose docstring claimed an unenforced invariant. The tap-once invariant is enforced by `dispatch_op` being the only `fetch_add` writer to `EMIT_TAP` — the newtype added no protection.
- **M2 (Medium, hygiene):** `DUCKDB_RESERVED` extended with 20 keywords likely to collide with Spark corpus column names (`left`, `right`, `full`, `inner`, `outer`, `cross`, `natural`, `join`, `qualify`, `pivot`, `unpivot`, `struct`, `map`, `list`, `sample`, `over`, `partition`, `range`, `rows`, `groups`).
- **M5 (Medium, hygiene):** Test rename `dispatch_op_single_row_emits_select_from_empty` → `dispatch_op_single_row_emits_bare_select` (assertion is `assert_eq!(sql, "SELECT")` — no FROM).

## Perf pass — 4 items applied

- **H1 (HIGH):** `quote_ident`'s safe-identifier fast path was silently defeated by `is_safe_identifier` calling `.to_lowercase()` — allocating on every call despite the §5.6 anchor's zero-alloc claim. Replaced lowercased-String reserved-word check with byte-level `ascii_ci_cmp` comparator. Fast path now allocates zero heap memory.
- **M1 (MEDIUM):** `DUCKDB_RESERVED.contains` linear scan (111 words post-M2) replaced with `binary_search_by(|w| ascii_ci_cmp(w.as_bytes(), name.as_bytes()))`. Added invariant guards asserting `DUCKDB_RESERVED` is lowercase-ASCII + ascending-sorted so future edits can't silently break the precondition.
- **M2 (MEDIUM):** Seven list-building renderers (`render_values`/`render_local_relation`/`render_file_scan`/`render_project`/`render_sort`/`render_with_columns`/`render_drop_columns`) rewritten to build SQL directly into a pre-allocated `String` buffer instead of intermediate `Vec<String>` + `.join(", ")`. Byte-identical SQL verified.
- **M3 (MEDIUM):** `is_aggregate_name` `.to_lowercase()` allocation replaced with `AGGREGATE_NAMES.iter().any(|n| n.eq_ignore_ascii_case(&f.name))`.
